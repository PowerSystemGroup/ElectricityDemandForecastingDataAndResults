# Electricity Demand Forecasting Data And Results
This repository stores the data and results required for monthly electricity demand forecasting.
# BiLSTM-TPA with DCNN-BiGRU-Attention Network (BLT-DCBGA) Model
This repository contains the experimental data and corresponding experimental program codes in the paper "Monthly Electricity Demand Forecasting Based on BiLSTM-TPA with DCNN-BiGRU-Attention Network".
# Dataset Description
Datasets include: Experiment 1: the Australian Energy Market Operator (AEMO) dataset Experiment 2: the European Network of Transmission System Operators for Electricity (ENTSO-E) dataset Experiment 3: the Electricity Demand Data of a Province in China (EDD-PC) dataset.
# Data Structure
The AEMO dataset contains electricity demand data for Australia, the ENTSO-E dataset contains electricity demand data for 35 countries or regions, and the EDD-PC dataset contains electricity demand data for a province in China.
# Usage
This dataset supports research on monthly electricity demand forecasting, the AEMO, ENTSO-E and EDD-PC datasets provide stable and reliable input for algorithm validation.
